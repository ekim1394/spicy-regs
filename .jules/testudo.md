# Testudo's Journal

## 2025-02-18 - [Initial Testing Setup] **Issue:** The codebase completely lacked a testing infrastructure and unit tests, leaving critical logic like SQL query generation unverified and potentially vulnerable. **Learning:** Even when tools like `bun` are used, explicit configuration (scripts, types) is necessary to make testing accessible and discoverable. **Action:** Always verify `package.json` scripts and existence of test files before assuming a testing culture exists.
