## 2024-05-23 - [Frontend Testing Infrastructure] **Issue:** The frontend lacked any testing infrastructure (missing `test` script, `bun-types` configuration, and any tests), making it impossible to verify logic changes or catch regressions. **Learning:** Even simple utility functions like SQL query builders can have subtle path construction logic that benefits from unit testing. Starting with a solid foundation (scripts, types) is prerequisite to building a "wall of reliable tests". **Action:** Always check `package.json` for a test script and `tsconfig.json` for correct type definitions in Bun projects before attempting to write tests.
