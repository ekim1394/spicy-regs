## 2024-05-24 - Search Input Interaction Pattern
**Learning:** Search inputs without a "clear" action force users to repeatedly backspace or manually select text to reset their query, which is frustrating on both mobile and desktop.
**Action:** Always include a clear button (x) inside search inputs that appears when there is content. Ensure it returns focus to the input so the user can immediately type a new query. Use `type="search"` for semantic correctness and potential native UI enhancements.
